# Srikesh | Portfolio Website

A modern, responsive personal portfolio website showcasing my skills, experience, and passion for technology as a Computer Science student. This project features a sleek, dark-themed design with interactive elements and smooth animations.

## 🌟 Features

-   **Responsive Design**: Fully responsive layout that ensures a seamless experience across desktops, tablets, and mobile phones.
-   **Interactive UI**:
    -   **Typing Effect**: Dynamic typing animation in the Hero section.
    -   **Smooth Scrolling**: Navigation links scroll smoothly to the respective sections.
    -   **Scroll Animations**: Elements fade in and slide up as you scroll down the page using the Intersection Observer API.
    -   **Staggered Skills Reveal**: Skill cards animate in from alternating sides (left/right) for a polished look.
-   **Modern Aesthetics**:
    -   Dark mode theme with custom gradients (`#38bdf8` to `#818cf8`).
    -   Glassmorphism effects on cards and navigation.
    -   Glowing accents and hover effects.

## 🛠️ Technologies Used

-   **HTML5**: Semantic markup for structure.
-   **CSS3**:
    -   Flexbox & CSS Grid for layout.
    -   CSS Variables for consistent theming.
    -   Media Queries for responsiveness.
    -   Keyframe animations.
-   **JavaScript (ES6+)**:
    -   DOM Manipulation.
    -   `IntersectionObserver` for performance-friendly scroll animations.
-   **Font Awesome**: For social and UI icons.
-   **Google Fonts**: 'Space Grotesk' (Headings) and 'Outfit' (Body text).

## 🚀 Getting Started

To view this portfolio locally on your machine:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/srikesh-10/portfolio.git
    ```
2.  **Navigate to the project folder**:
    ```bash
    cd portfolio
    ```
3.  **Open the website**:
    -   Simply open `index.html` in your preferred web browser.
    -   Or use a live server extension (like Live Server in VS Code) for a better development experience.

## 📂 Project Structure

```
├── index.html      # Main HTML structure
├── style.css       # Global styles, variables, and responsive design
└── script.js       # Typing effect, valid navigation, and scroll animations
```
